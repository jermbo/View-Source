# Project isolation with a single shared escape hatch

Each Project is meant to explore a radically different, non-average aesthetic — the point of the experiment is to see what agent-assisted design can do when it isn't pulled toward a shared system. So Projects share no CSS, layout, or components with each other or with the meta layer (root home + World pages), and each is free to reinvent its own markup and design language from scratch.

The one exception is the Escape Hatch: a single, visually consistent, deliberately non-diegetic widget present on every project page, linking to root home and listing sibling projects in that world. Without it, a visitor dropped into an isolated project has no way back or across; a shared, tool-like widget provides that without contaminating any project's own visual language, since it's designed to read as "not part of this design" rather than blending in.

This was a deliberate trade-off of discoverability against authenticity of each design experiment, and it's meant to hold as more Worlds and Projects are added — a future project should not "fix" the lack of shared styling by importing a common design system.
