# View-Source

An experiment in rediscovering visual design in the age of agents. The site is a hub into a growing set of standalone design experiments — each pushed toward a distinct, non-average aesthetic rather than the generic "middle of the road" output agents tend to converge on.

## Language

**World**:
A top-level fictional identity/domain the experiment explores (e.g. Cosmic Strawberry, Web Design Eras, Mint Panther Corp). Each world has its own design philosophy and fictional purpose ("client"), and contains one or more Projects. New worlds are added over time and aren't limited to any fixed theme (a band site, a bakery, a craft shop — anything is fair game).
_Avoid_: Category, client

**Project**:
One fully-realized design concept within a World, built out with its own UI Kit and a handful of Pages (always including a home page). A project's page set is derived from that concept's own internal logic (nav, tone, fiction), not a fixed template — different projects can have entirely different page counts and names. For Cosmic Strawberry and Mint Panther, a project is a curated pick from that world's inspiration sheet (not every concept sheet graduates into a project). For Web Design Eras, each of the six eras is automatically a project.
_Avoid_: Concept (use for an inspiration-sheet entry that hasn't been chosen as a project yet), client project

**Page**:
A single route inside a Project (e.g. home, work, kit). Pages within a project share that project's bespoke design; pages across different projects share nothing.

**UI Kit**:
A linkable Page within a Project that displays that project's type scale, color palette, and components in its own bespoke style — browsable like any other page, not a separate reference document.

**Escape Hatch**:
The one shared mechanism that breaks a Project's isolation: a single, consistent, deliberately non-diegetic tucked-away widget present on every project page. It looks like tooling, not part of any project's design. It links to the root home and lists sibling Projects within the current World. Its design never varies by World or Project.
_Avoid_: Nav widget, control tab

**Meta layer**:
The root home page and every World page. Together they form one consistent, shared design system (distinct from the radical per-project isolation) — the "frame" around the experiment. World pages describe that world's design philosophy and fictional purpose, and gallery-link to its Projects; the meta layer also carries navigation between Worlds.
